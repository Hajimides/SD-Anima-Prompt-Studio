# 🎨 Prompt Studio — Optimized V2（带前端数据编辑器）

> 在 Optimized V1 基础上增加了**可视化数据编辑器**，完全不需要接触代码和 JSON 文件，直接在浏览器里增删改提示词、分类、多语言文案和图片链接。

---

## ✨ V2 新增特性

- **🛠️ 可视化数据编辑器**：点击顶部工具栏的 🛠️ 按钮，打开编辑面板
- **💾 显式保存 / 取消**：编辑器内所有修改先进入草稿，点击「保存编辑」才会写入 localStorage；关闭时如有未保存改动会弹窗确认
- **📦 数据本地持久化**：确认保存后，数据写入浏览器 localStorage，刷新页面不会丢失
- **📤 导出/导入 JSON**：改好后可以导出数据文件，分享给他人或替换项目默认数据
- **↺ 一键重置默认**：改乱了可以随时恢复初始数据（同样需要点「保存编辑」生效）
- **🔄 拖拽排序**：分类和提示词组都支持拖拽排序，**只有 ⋮⋮ 把手可拖动**
- **📷 图片上传**：直接在编辑器里上传人物卡片图片（自动压缩转 base64）
- **实时预览**：分类排序、新增/删除分类、分组增删等操作会即时反映到主界面

## 🚀 快速开始

### 双击启动（推荐）

Windows 用户直接双击目录下的 **`启动.bat`**：

- 首次会自动安装依赖
- 随后自动启动开发服务器
- 浏览器打开终端显示的地址即可（默认 `http://localhost:5173/`）

### 命令行启动

```bash
cd optimized-v2
npm install
npm run dev
```

退出开发服务器：在终端按 `Ctrl + C`，端口会立即释放。

## 📖 使用前端编辑器

### 打开编辑器

点击顶部工具栏右侧的 **🛠️ 编辑数据** 按钮。

### 界面说明

编辑器分为左右两栏：

- **左侧**：分类列表
  - 点击分类名称切换
  - 点击 ✎ 编辑分类名称、图标、颜色
  - 点击 🗑 删除分类
  - 点击右上角「+ 新增」添加新分类
- **右侧**：当前分类下的提示词组
  - 每个组可以编辑简体/繁体/英文名称
  - 编辑英文提示词（每行一个）
  - 编辑图片链接
  - 点击「+ 新增提示词组」添加
  - 点击 🗑 删除

### 保存修改

编辑器里的修改**不会自动保存**。改完后点击右上角的 **「保存编辑」**，数据才会写入 localStorage 并同步到主界面。

如果点击 **「取消」** 或 **×** 关闭时有未保存的改动，会弹出确认框：「是否保存编辑？」

### 导出数据

点击编辑器顶部的 **📤 导出 JSON**，会把当前所有数据下载为 `prompt-studio-data.json`。

你可以把这个文件：
- 发给朋友，让对方用「导入 JSON」功能加载
- 替换项目里的 `src/data/promptLibrary.json` 等文件（需要简单整理）

### 导入数据

点击 **📥 导入 JSON**，选择之前导出的文件即可。导入后仍处于草稿状态，需要点 **「保存编辑」** 才会真正覆盖本地数据。

### 重置默认

点击 **↺ 重置默认**，所有修改会恢复为项目初始数据。同样需要点 **「保存编辑」** 才会真正生效。

## 🏗️ 数据存储说明

确认保存后的数据放在浏览器 localStorage 中，刷新页面不会丢失。

如果想让修改成为项目默认数据：

1. 在编辑器中改好数据
2. 点击「导出 JSON」
3. 打开导出的 JSON 文件
4. 把对应内容复制到 `src/data/promptLibrary.json` 和 `src/i18n/*.json` 中
