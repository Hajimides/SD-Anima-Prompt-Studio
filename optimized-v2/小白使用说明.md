# 🎨 Prompt Studio 优化版 V2 — 小白使用说明

> 这份说明写给完全不懂前端的朋友。**优化版 V2 最大的好处是：你不需要碰任何代码文件，直接在浏览器里就能改数据。**

---

## 📁 先认识一下文件

打开 `SD-Anima-Prompt-Studio-main/optimized-v2/` 文件夹：

```
optimized-v2/
├── index.html              ← 网页入口
├── package.json            ← 项目配置（不用改）
├── src/                    ← 程序代码（一般不用改）
├── public/                 ← 图片、图标等静态文件
│   └── images/             ← 人物卡片图片放这里
└── README.md
```

> 💡 V2 版本你只需要关心 `public/images/` 放图片，其他数据全在浏览器里改。

---

## 🚀 第一步：让项目跑起来

### 1. 安装 Node.js

浏览器打开：👉 https://nodejs.org/

下载 **LTS（长期支持版）**，一路下一步安装。

装好后，按 `Win + R`，输入 `cmd` 回车，打开命令行，输入：

```bash
node -v
npm -v
```

如果显示版本号，说明安装成功。

### 2. 安装依赖

在命令行里进入文件夹：

```bash
cd 桌面/SD-Anima-Prompt-Studio-main/optimized-v2
```

然后运行：

```bash
npm install
```

第一次会下载一些东西，等几分钟。看到光标回到 `>` 就是好了。

### 3. 启动

#### 方式一：双击启动（最简单）

直接双击文件夹里的 **`启动.bat`** 文件。

- 第一次运行会自动检测并安装依赖
- 之后会自动启动开发服务器
- 终端里会显示访问地址，例如：

```
➜  Local:   http://localhost:5173/
```

用浏览器打开这个地址，就能用了。

#### 方式二：命令行启动

在 `optimized-v2` 文件夹地址栏输入 `cmd` 回车，然后运行：

```bash
npm run dev
```

### 4. 退出

不想用了，回到终端窗口，按 **`Ctrl + C`** 即可停止。端口会立即释放，不会被一直占用。

> 如果 5173 端口被别的程序占用，Vite 会自动跳到 5174、5175……并在终端里显示实际地址，照那个地址打开就行。

## 🛠️ 第二步：用前端编辑器改数据（重点）

### 打开编辑器

点击页面顶部工具栏右侧的 **🛠️ 编辑数据** 按钮。

会弹出一个大窗口，这就是数据编辑器。

### 编辑器界面

```
┌─────────────────────────────────────────────────────────────────────┐
│  数据编辑器    [导入JSON] [导出JSON] [重置默认] [取消] [保存编辑]  [×]  │
├──────────────────┬──────────────────────────────────────────────────┤
│                  │                                                  │
│   分类  [+新增]  │   当前分类的提示词组                              │
│                  │                                                  │
│   ✨ 质量        │   ┌─────────────────────────┐                    │
│   🖼️ 风格       │   │ ⋮⋮ 简体: 杰作            │                    │
│   👥 主体       │   │     繁体: 傑作           │                    │
│   ...            │   │     英文: Masterpiece    │                    │
│                  │   │     英文提示词:          │                    │
│   （点击分类     │   │     masterpiece          │                    │
│    切换）        │   │     best quality         │                    │
│                  │   │     ...                  │                    │
│                  │   │     图片链接: ...        │                    │
│                  │   └─────────────────────────┘                    │
│                  │   [+ 新增提示词组]                               │
│                  │                                                  │
└──────────────────┴──────────────────────────────────────────────────┘
```

> 💡 **重要变化**：编辑器里的修改**不会自动保存到本地**。你必须点右上角的 **「保存编辑」**，修改才会真正写入浏览器本地存储。点 **「取消」** 或 **×** 关闭时，如果有未保存的改动，会弹出提示问你是否保存。

## ➕ 第三步：新增一条提示词

1. 在编辑器左侧点击要添加到的分类（比如「质量」）
2. 点击右侧的 **「+ 新增提示词组」**
3. 会出现一个新的卡片
4. 填写：
   - **简体**：中文显示名
   - **繁体**：繁体中文显示名
   - **英文**：英文显示名
   - **英文提示词**：每行写一个，这就是实际生成到 Prompt 里的内容
   - **图片链接**：人物卡片才需要填，普通提示词不用填
5. 改完后点击编辑器右上角的 **「保存编辑」**

**英文提示词示例：**

```
masterpiece
best quality
ultra detailed
8k resolution
```

---

## ✏️ 第四步：修改已有提示词

直接点击要改的输入框改文字，输入框里可以正常点击、选中文本。改完后点击 **「保存编辑」**。

> 现在编辑器支持**实时预览**：你修改分类、排序、新增/删除分组后，主界面会立刻跟着变化（如果文字内容没马上变，点一下卡片外面或按 `Tab` 切到下一个输入框即可）。

---

## 🗂️ 第五步：新增一个分类

1. 点击编辑器左侧顶部的 **「+ 新增」** 按钮
2. 按提示输入：
   - 分类标识（英文，比如 `effects`）
   - 简体中文名称
   - 繁体中文名称
   - 英文名称
   - 图标 emoji（比如 ✨）
   - 颜色（从 `indigo/purple/pink/...` 里选一个）
3. 新分类就出现在左侧列表里了
4. 点击新分类，往里面加提示词组
5. 最后点 **「保存编辑」**

## 🖼️ 第六步：换人物卡片图片

### 方法 A：用本地图片

1. 把你的图片放到 `optimized-v2/public/images/` 文件夹
2. 打开编辑器，找到「人物」分类里对应的人物
3. 在「图片链接」里填：

```
./images/你的图片.jpg
```

### 方法 B：用网络图片

直接在「图片链接」里填图片网址：

```
https://example.com/my_char.jpg
```

### 方法 C：直接上传图片（推荐）

1. 在编辑器里找到要换图片的提示词组
2. 点击 **📷 上传图片** 按钮
3. 从电脑里选择一张图片
4. 图片会自动压缩并保存

> 💡 上传的图片会转成 base64 格式保存在数据里，不用放到 `public/images/` 文件夹。
> ⚠️ 建议上传较小的图片（几百 KB），太大的图片会让数据文件变得很臃肿。

## 🌐 第七步：改界面文字

编辑器暂时不支持直接改界面文字（如按钮文字）。如果需要改：

1. 用 VS Code 打开 `optimized-v2/src/i18n/zh-CN.json`
2. 改引号里的文字
3. 保存，刷新浏览器

## 🔄 第八步：拖拽排序

### 给分类排序

编辑器左侧的分类列表支持拖拽：

1. 鼠标按住分类前面的 **⋮⋮** 拖动把手
2. 拖动到想要的位置
3. 松开鼠标，顺序就变了

### 给提示词组排序

编辑器右侧的每个提示词组卡片也支持拖拽：

1. 鼠标按住卡片顶部的 **⋮⋮** 拖动把手
2. 拖动到想要的位置
3. 松开鼠标，顺序就变了

> 💡 现在排序会**实时反映到主界面**：拖动分类后，左侧边栏和内容区会立刻按新顺序显示。
> ⚠️ 只有 **⋮⋮** 把手能拖动，输入框里可以正常选文字，不会再被拖走了。

---

## 💾 第九步：保存和分享你的数据

### 数据存在哪里？

你在编辑器里的所有修改，**必须点「保存编辑」后**才会写入**浏览器本地**（localStorage）。刷新页面不会丢。

### 导出数据

点击编辑器顶部的 **📤 导出 JSON**，会下载一个 `prompt-studio-data.json` 文件。

你可以：
- 把这个文件备份到自己电脑
- 发给朋友，朋友用「导入 JSON」加载

### 导入数据

点击 **📥 导入 JSON**，选择之前导出的文件。

> 导入后数据会先进入编辑器的草稿状态，记得点 **「保存编辑」** 才会真正覆盖本地数据。

### 重置默认

如果改乱了，点击 **↺ 重置默认**，会恢复成项目初始数据。

> 重置后也需要点 **「保存编辑」** 才会真正生效；点取消可以反悔。

---

## 🚀 第十步：发布到网上

改好后，运行：

```bash
npm run build
```

会生成 `optimized-v2/dist/` 文件夹，里面就是可以发到网上的版本。

### GitHub Pages

1. 把 `dist/` 里的所有内容上传到你的 GitHub 仓库
2. 仓库设置 → Pages → Source 选对应分支和目录
3. 等 1-2 分钟，得到一个网址

> ⚠️ 不要直接双击 `dist/index.html` 打开，需要部署到服务器上才能正常显示。

## ❓ 常见问题

### Q1：改完关闭编辑器，主界面没变化？

A：请先确认你是点了 **「保存编辑」** 才关闭的。如果点了「取消」，改动会被丢弃。正常保存后主界面会实时更新；如果没更新，按 `Ctrl + F5` 强制刷新即可。

### Q2：编辑器里的修改会保存多久？

A：只有点 **「保存编辑」** 后，数据才会写入浏览器本地。只要不清除浏览器缓存/数据，就会一直存在。换电脑或换浏览器需要重新导入数据。

### Q3：想把修改变成项目默认数据怎么办？

A：
1. 在编辑器里改好
2. 点击「导出 JSON」
3. 把 JSON 文件里的内容复制到项目源码的 JSON 文件里（需要一定技术基础，或请懂前端的朋友帮忙）

### Q4：运行 `npm install` 报错？

A：检查 Node.js 是否安装成功。网络慢的话多试几次，或换手机热点。

### Q5：页面空白只有背景？

A：看浏览器控制台（按 F12 → Console）有没有红色报错。通常是 JSON 格式或文件路径问题。

### Q6：在编辑器输入框里没法选中文字？

A：这个已经修复了。现在**只有 ⋮⋮ 把手能拖动**，输入框内可以正常点击、定位光标、按住鼠标选中文本。

### Q7：关闭终端后还能访问页面吗？

A：不能。`npm run dev` 是开发服务器，关掉终端（或按 `Ctrl + C`）后服务就停了，页面也访问不了。想再次使用，需要重新运行 `npm run dev`。
